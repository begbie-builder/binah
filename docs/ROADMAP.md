# From a beginner app to a full Hebrew course

The current release is functional from guest onboarding through lessons, review, and literacy practice. A Duolingo-scale language program needs sustained content development and learner testing.

## Next: quality and depth

1. Educator review of all 128 entries, feminine variants, niqqud, full spelling, stress, and meaning; version each content correction.
2. Licensed native recordings, listening discrimination, speed controls, and transcript reveal. Device speech is a fallback, not the content production plan.
3. Explicit `unpointed` and allowed-answer fields instead of a small corpus-specific spelling map.
4. Separate print-recognition and real handwriting guides, educator-reviewed shape models, optional stroke-by-stroke coaching.
5. Longer multi-turn authored dialogues, learner-controlled prompts, and typing alternatives accepted by meaning rather than one surface string.
6. Accessibility audit: contrast, keyboard/focus, screen readers, zoom, and equivalence of literacy activities.

## Extend the course

| Stage | New communicative scope | New language systems |
| --- | --- | --- |
| Foundations 2 | All weekdays, times, ages, numbers/prices, family, routine | Full pronouns, noun/adjective agreement, plural patterns, simple preposition suffixes |
| Everyday independence | Shops, housing, transport, phone, appointments | Present tense families, infinitives/modal requests, object marker et, possession, construct state |
| Tell your story | What happened, invitations, plans | Past and future strong verbs, high-frequency weak verbs, comparison, negation |
| Connected speech | Reasons, conditions, narratives, reported conversations | Subordinate and relative clauses, binyan contrasts, discourse markers, register |
| Authentic literacy | Messages, forms, notices, articles, short stories | Unpointed ambiguity, word families, register, idioms, reading strategies |
| Advanced pathways | Academic/work communication, nuanced debate, literature | Specialized vocabulary, pragmatics, stylistic choices, historical comparison |

These are planned modules, not locked placeholder lesson cards pretending to exist today.

## Product growth

- Firebase emulator tests and a live staging project for Google popup, transaction contention, and rules isolation.
- Richer progress model: per-event XP IDs for additive multi-device activity without double counting, clock-independent review conflict handling, global reset generations, and active-session checkpoints.
- Service-worker update notification and cache versioning generated from build hashes.
- Optional reminders with explicit user consent, privacy-preserving learning metrics only if requested, no ad tracking.
- Content authoring and review workflow; sustainable human review before adding generative conversation.
- Account data deletion and a clearly documented retention policy before a large public launch.
